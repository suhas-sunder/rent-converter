# Home Page Style Source Of Truth

The current home page is the styling baseline for the rest of RentConverter.com.

- Use the existing light theme: sky page background, white calculator shell, slate text, sky accents, and emerald result emphasis.
- Avoid borders and shadows as the main shape language. Prefer spacing, fill color, rounded sections, and contrast.
- Keep calculator pages tight near the top. Do not add extra whitespace above the first input row.
- Use a white outer calculator shell with no border or shadow.
- All headings (`h1` through `h6`) use the shared title font family while keeping their existing size, weight, spacing, and color classes.
- Use `bg-slate-100` for inputs and selects, with readable slate text and sky-tinted hover/focus states.
- Use a soft sky result panel with an integrated sky-to-emerald accent strip as the first child, not an absolute overlay.
- Do not place the primary emerald headline result inside an emerald/green background. Primary values sit directly on the sky panel.
- Use plain white rounded result tiles inside the result panel.
- Use soft emerald blocks for comparison or explanation callouts.
- Use stronger secondary text contrast, generally `text-slate-700` instead of lighter gray copy.
- Keep one visible print/save PDF control near the calculator header where possible.
- Avoid repeating utility/disclaimer blocks below the result when they are not needed.
- Keep footer and navigation clean: no border/shadow dependency, clear color contrast, and simple grouped sections.
